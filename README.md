## GitHub Pages

Upload the contents of this folder to the repository's `main` branch. Keep the capital **A** in the `Assets` folder name, and place `index.html` and `favicon.ico` at the repository root.

In the repository settings, open **Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

The official company logo is used in the header. The circular GR mark is supplied as both `favicon.ico` and `Assets/favicon.png`.
